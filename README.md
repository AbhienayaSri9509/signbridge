# Sign Bridge AI

## Overview

Sign Bridge AI is an AI-powered accessibility platform that enables seamless communication between deaf or hard-of-hearing individuals and non-signers.

It supports real-time sign recognition, sign-to-text and speech, text-to-sign videos, and multilingual communication.

## Key Features

- Real-time sign language recognition using webcam
- Sign-to-text and speech conversion
- Text-to-sign human/avatar video generation
- Two-way communication support
- English and Tamil language support
- Interactive 3D sign avatar
- Modern, responsive, and accessible UI

## How It Works

### Sign Language to Text and Speech

Users perform signs, AI recognizes gestures, and text and speech are generated.

### Text to Sign Language

Users enter text, the Sign Avatar Server processes it, and sign language animation or video is displayed.
